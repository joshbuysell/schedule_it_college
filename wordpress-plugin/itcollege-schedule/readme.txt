== Встановлення ==
1. Плагіни → Додати новий → Завантажити плагін → itcollege-schedule.zip → Активувати.
2. Налаштування → Розклад ІТ коледжу → вкажіть адресу системи розкладу.
3. На сторінку «Розклад» додайте шорткод [itcollege_schedule].
