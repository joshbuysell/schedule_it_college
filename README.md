# Розклад ІТ коледжу Львівської політехніки

Вебсистема розкладу занять для [Фахового коледжу інформаційних технологій НУ «Львівська політехніка»](https://itcollege.lviv.ua).
Замінює скановані PDF-роздруківки зручним розкладом для студентів і редактором для навчальної частини.

## Можливості

**Студентам**
- Пошук групи, викладача чи аудиторії (працює навіть у неправильній розкладці та транслітом).
- Тижнева сітка на компʼютері, «день за днем» на телефоні, поточна пара, чисельник/знаменник (у вихідні — наступний тиждень).
- Заміни на конкретну дату: видно в розкладі групи, на головній і у віджеті на сайті коледжу.
- «Моя група», підписка на календар (Google / Apple, оновлюється сама й враховує заміни), друк.
- Push-сповіщення про заміни групи (Android, компʼютер, iPhone з головного екрана) і ранковий розклад на день — без сторонніх сервісів.
- Встановлення на телефон як застосунок (PWA) і перегляд без інтернету.
- Підказка «три кроки» для новачків і сторінка «Довідка» (`/help`) для студентів, викладачів і навчальної частини.
- Telegram-бот (необовʼязково): розклад на день, ранкова розсилка, сповіщення про заміни.

**Викладачам**
- Кабінет викладача (`/login`): свої пари на два тижні; кнопки «Інша аудиторія», «Потрібна заміна», «Скасувати пару», «Мене не буде цього дня» — заявки йдуть у навчальну частину.
- Свій розклад у календарі телефона, вільні аудиторії на будь-яку пару.
- Push-сповіщення про заміни у своїх парах і про рішення навчальної частини щодо заявок.

**Навчальній частині** (`/admin`)
- Редактор-сітка з підказками «вільний / зайнятий», перевіркою накладок, перетягуванням, потоками (одна пара для кількох груп).
- Заміни: за групою або «відсутній викладач», черга заявок від викладачів.
- Семестри: підготовка наступного семестру як чернетки (з копією поточного) і публікація одним натиском.
- Друк в офіційному форматі («ЗАТВЕРДЖУЮ», 4 групи на аркуш), QR-плакати для груп.
- Табло для холу (`/board`): поточна пара й час до дзвінка, заміни на сьогодні й завтра, вільні аудиторії, QR-код.
- Excel: експорт розкладу й навантаження, імпорт розкладу за шаблоном.
- Користувачі й ролі (адміністратор, навчальна частина, викладач), доступи для всіх викладачів одним натиском, історія змін.

## Дані

Офіційний розклад на сайті коледжу — це скан-PDF без текстового шару
([джерело](https://itcollege.lviv.ua/rozklad-2-2025-2026/)). Його 12 сторінок розшифровано в простий текстовий формат
`prisma/data/schedule-2025-2026-sem2.txt` (50 груп, 908 занять, 86 викладачів, 55 аудиторій), який імпортує `prisma/seed.ts`.
Повні імена викладачів і циклові комісії взято зі сторінок циклових комісій через WordPress REST API сайту.

> Після імпорту система виявила 20 накладок аудиторій, які є і в оригінальному PDF (напр. ауд. 404, понеділок, 3 пара — МТ-12 і МТ-230).
> Варто звірити їх з навчальною частиною: частина може бути помилками розшифровки.

## Запуск локально

Потрібні Node.js 20+ і PostgreSQL (на macOS: `brew install postgresql@16 && brew services start postgresql@16`).

```bash
npm install
createdb schedule
cp .env.example .env          # вкажіть свого користувача Postgres, AUTH_SECRET і ADMIN_PASSWORD
npm run db:push               # створює таблиці
npm run db:seed               # імпорт розкладу та обліковий запис навчальної частини
npm run dev                   # http://localhost:3000
```

Вхід у редактор: `/admin`, email і пароль — з `.env` (`ADMIN_EMAIL`, `ADMIN_PASSWORD`).

Інші команди: `npm test` — автотести (парсер, чисельник/знаменник, накладки, заміни, навантаження, пошук);
`npm run e2e` — наскрізні тести в браузері (див. нижче);
`npm run check` — звіт про накладки в розкладі.

## Інтеграція з сайтом коледжу (WordPress)

Розклад показується прямо на сторінці «Розклад» сайту itcollege.lviv.ua замість PDF — у кольорах і шрифті сайту.
Покрокова інструкція з готовим кодом — на сторінці `/integration` (посилання «Для сайту коледжу» внизу сайту).

**Варіант 1 — блок «Власний HTML»** (достатньо прав редактора WordPress):
```html
<div id="itc-schedule"></div>
<script src="https://<адреса-розкладу>/embed.js" async></script>
```
`embed.js` створює iframe з `/embed`, сам підлаштовує висоту і записує вибрану групу в адресу сторінки
(`…/rozklad-2-2025-2026/#schedule=g:КІ-21`), тож посиланням на розклад групи можна ділитися.
Для однієї групи: `<div id="itc-schedule" data-group="КІ-21"></div>`.

**Варіант 2 — плагін** (потрібні права адміністратора): `wordpress-plugin/itcollege-schedule`
(архів для встановлення — `public/downloads/itcollege-schedule.zip`, перезбирається `npm run plugin:zip`).
Додає шорткод `[itcollege_schedule]` / `[itcollege_schedule group="КІ-21"]` і сторінку налаштувань з адресою системи.

**Блок «Зміни в розкладі»** для головної сторінки чи бічної панелі — заміни на сьогодні й завтра:
```html
<div id="itc-changes" data-link="https://itcollege.lviv.ua/schedule/"></div>
<script src="https://<адреса-розкладу>/embed.js" async></script>
```
`data-link` — сторінка з повним розкладом, куди ведуть назви груп. У плагіні: `[itcollege_schedule_changes link="…"]`.

**Публічне API** (`/api/v1`, CORS відкрито): групи, розклад групи / викладача / аудиторії, пошук, `.ics`.

**Як це виглядатиме:** `demo/college-page/index.html` — локальна копія сторінки «Розклад» з сайту коледжу, де PDF
замінено віджетом (не комітиться, лише для перегляду). Запуск: `npx serve -l 5600 demo/college-page` при запущеному
`npm run dev -- -p 3100`.

## Розміщення онлайн (безкоштовно: Vercel + Neon)

1. [vercel.com](https://vercel.com) → увійти через GitHub → **Add New → Project** → імпортувати цей репозиторій.
2. **Settings → Environment Variables:** `AUTH_SECRET` (результат `openssl rand -hex 32`), `ADMIN_EMAIL`, `ADMIN_PASSWORD`.
3. **Storage → Create Database → Neon (Postgres)** → підключити до проєкту. Vercel сам додасть `DATABASE_URL` і `DATABASE_URL_UNPOOLED`.
4. **Deployments → Redeploy.** Під час збірки (`vercel-build`) створюються таблиці, у порожню базу імпортується розклад,
   а пароль адміністратора береться з `ADMIN_PASSWORD` (змінили змінну → Redeploy → пароль оновлено).
5. Необовʼязково: `PUBLIC_URL` = адреса сайту (для коду вставки на `/integration` і QR-кодів).
6. Telegram-бот: створіть бота в @BotFather, додайте `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET` і `CRON_SECRET`,
   після розгортання натисніть «Підключити» в **Налаштуваннях**.
7. Ранкова розсилка (push і Telegram) запускається Vercel Cron (`vercel.json` → `/api/digest`), для неї потрібен `CRON_SECRET`.
   Push-сповіщення окремих налаштувань не потребують: ключі VAPID створюються автоматично й зберігаються в базі.

Інші варіанти: **Docker** — `docker compose up -d --build` (разом із Postgres); **Heroku** — є `Procfile`
(додайте Heroku Postgres і змінну `DATABASE_URL_UNPOOLED` з тим самим значенням, що `DATABASE_URL`).
Сайт коледжу працює через HTTPS, тому і система розкладу має бути на HTTPS (Vercel дає його автоматично).

## Резервні копії та моніторинг

- **Вручну:** `npm run db:backup` — знімок бази в `backups/` (потрібен `pg_dump`). Відновлення:
  `pg_restore --clean --if-exists --no-owner -d "$DATABASE_URL" backups/<файл>.dump`.
- **Щодня автоматично:** GitHub Actions (`.github/workflows/backup.yml`) робить `pg_dump`, шифрує його (AES-256) і зберігає
  30 днів у розділі Actions → Artifacts. Потрібні секрети репозиторію `DATABASE_URL` і `BACKUP_PASSPHRASE`.
  Розшифрування: `gpg -d schedule-<дата>.dump.gpg > schedule.dump`.
- **Перевірка роботи:** `/api/health` відповідає `ok`, якщо працює база. `.github/workflows/uptime.yml` кожні пів години
  в навчальний час перевіряє сайт (змінна репозиторію `PUBLIC_URL`); якщо сайт не відповідає, GitHub надсилає лист.
  Neon додатково дозволяє відновити базу на момент часу в межах вікна історії свого тарифу.

## Наскрізні тести

`npm run e2e` проходить систему так, як нею користуються люди (Playwright, 38 сценаріїв):

- **Студент** (компʼютер і iPhone): пошук групи навіть у неправильній розкладці, «моя група», пари на сьогодні з позначкою
  «зараз», сповіщення, підписка на календар, сторінки без горизонтального прокручування.
- **Викладач з телефона → навчальна частина → студенти:** доступи для всіх викладачів, вхід у кабінет, заявки «Інша аудиторія»
  й «Скасувати пару», підтвердження й відхилення, заміна викладача з підказкою «вільний», результат на сторінках груп.
- **Новий семестр:** чернетка з копії, нова пара з перевіркою накладок, студенти не бачать чернетку, публікація, повернення.
- **Табло й вставка на сайт:** табло під час пари, на перерві й увечері; два рядки коду на «чужій» сторінці.
- **Доступність** (axe, WCAG 2.1 AA): публічні сторінки, кабінет викладача й усі розділи адмінки.

Тести працюють з окремою локальною базою `schedule_e2e` (створюється й очищається сама, з іншими базами не працює) і з
«замороженим» часом — середа, 10:30, друга пара. Потрібна локальна PostgreSQL; браузери ставляться командою
`npx playwright install chromium webkit`. Звіт: `npx playwright show-report`.

## Технології

Next.js 15 (App Router, React 19, TypeScript) · Tailwind CSS 4 · Prisma ORM + PostgreSQL · JWT-сесії (`jose`, `bcryptjs`) · Zod · Web Push (`web-push`, VAPID).

```
src/app            сторінки (публічні, /admin, /embed) та API (/api/v1 — публічне, /api/admin — під авторизацією)
src/components     Timetable (сітка/день), Search, «Моя група»
src/lib            schedule.ts (чисельник/знаменник, кольори, пошук), conflicts.ts (накладки), queries.ts, auth.ts
prisma             схема БД, імпорт, розшифрований розклад
```
